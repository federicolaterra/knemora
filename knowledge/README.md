# Knemora Knowledge Vault

This directory is the live, portable Markdown Knemora Wiki. The backend owns validated
compilation, atomic updates, indexes, audit state, and the native Second Brain graph. Compatible
external Markdown viewers are optional and do not need to be running.

See `wiki-schema.md` and the public [Wiki guide](../docs/open-source/wiki.md) before making manual
changes. Original uploads remain immutable under the configured source store. Files under
`sources/` are source manifests, not copies of the original bytes.
